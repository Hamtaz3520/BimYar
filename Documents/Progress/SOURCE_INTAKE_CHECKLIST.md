# چک‌لیست ورود فایل‌های واقعی پروژه BimYar

این چک‌لیست برای دریافت و جانمایی فایل‌های واقعی موجود پروژه تهیه شده است. در این مرحله هیچ فایل SQL، ماژول VBA یا منطق برنامه نباید بازسازی، حدس زده یا از نو تولید شود.

## الزامات امنیت و محرمانگی

- [ ] پیش از ورود هر فایل، محرمانه‌بودن محتوای آن بررسی شده است.
- [ ] هیچ فایل دارای اطلاعات واقعی و محرمانه مشتریان بدون بررسی وارد Repository نشده است.
- [ ] فایل‌های Microsoft Access و Excel پیش از قرارگرفتن در Repository از نظر وجود داده‌های واقعی مشتری بررسی شده‌اند.
- [ ] وجود کد ملی، شماره موبایل، آدرس و اطلاعات مالی در فایل‌های Access و Excel بررسی شده است.
- [ ] اطلاعات واقعی یا محرمانه شناسایی‌شده، پیش از ورود فایل به Repository حذف یا به‌شکل مناسب ناشناس‌سازی شده است.
- [ ] فایل‌های موقت و قفل Microsoft Access، از جمله فایل‌های دارای پسوند `.laccdb`، وارد Repository نشده‌اند.
