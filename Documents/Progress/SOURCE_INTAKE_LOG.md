## قواعد ورود فایل‌های واقعی

- هیچ SQL یا VBA نباید از روی نام فایل یا توضیحات پروژه بازسازی شود.
- فقط فایل واقعی دریافت‌شده باید وارد Repository شود.
- نام اصلی فایل‌ها و پسوند آن‌ها حفظ شود.
- فایل‌های دارای اطلاعات واقعی مشتریان قبل از Commit باید بررسی شوند.
- فایل‌های Access موقت یا Lock با پسوندهایی مانند `.laccdb` نباید وارد Repository شوند.
- قبل از هر Merge باید فهرست فایل‌های واردشده گزارش شود.
